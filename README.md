# tsegaye-misikir.github.io

Personal academic website of Tsegaye M. Tashu (University of Groningen), served by GitHub Pages at <https://tsegaye-misikir.github.io/>. GitHub Pages builds it with Jekyll.

## Where things live

- `_data/` holds the content:
  - `profile.yml`: name, position, links, CV and Scholar stats
  - `publications.yml`: every paper, with tags, links, BibTeX and the `selected` flag that puts it on the home page
  - `news.yml`, `people.yml`, `courses.yml` and `navigation.yml`
- `_layouts/default.html` and `_includes/` hold the shared page shell: head, nav, footer, publication row, news item and icons.
- `assets/css/` and `assets/js/` hold the styles and scripts. `site.*` is shared by every page; `home.css`, `publications.css` and `course.*` are page-specific.
- Pages:
  - `index.html` is the home page.
  - `publications.html` is the full list. It and `publications.bib` are generated from `_data/publications.yml`.
  - `NLP.html`, `llm.html` and `LTP.html` are the course pages.
  - `404.html` is the not-found page.
- `sitemap.xml` is generated by the `jekyll-sitemap` plugin.

## Common edits

- **Add a paper:** add an entry to `_data/publications.yml`. Set `selected: true` to also show it on the home page.
- **Add a news item:** add an entry at the top of `_data/news.yml`.
- **Show the CV button:** set `cv:` in `_data/profile.yml` to a URL or file path.

## Local preview

```bash
bundle exec jekyll serve
```

Use the `github-pages` gem. If the Sass build fails on non-ASCII characters, run with `LANG=C.UTF-8`.
